TurboVets DevOps Architecture

Containerized Node.js application deployed on AWS ECS Fargate with automated CI/CD, served via HTTPS through Application Load Balancer with custom Route 53 domain, infrastructure managed as code with CDKTF and GitHub Actions.

Docker ECS Fargate ALB ECR Route 53 ACM CDKTF GitHub Actions S3 + DynamoDB
🌐 End Users
Clients access the application via browser over HTTPS. HTTP requests are automatically redirected to HTTPS (301).
https://aws-docker-terrafrom-github-actions.marvinmeite.cloud
↓ HTTPS :443
Route 53 + ACM
Custom domain configured with Route 53 alias record pointing to ALB. SSL/TLS certificate from AWS Certificate Manager with DNS validation.
↓ routes to ALB
⚙️ GitHub Actions CI/CD
Automated Pipeline:
• Dev: Auto-deploy on push to main
• Staging/Prod: Manual via workflow_dispatch(environment)
• Build Docker image (multi-stage)
• Tag with commit SHA
• Push to ECR (auto-create repo)
• Deploy via cdktf deploy
• Zero-downtime rolling updates

Inputs:
• Secrets: AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY
• Repo vars: AWS_REGION, SERVICE_NAME, TF_STATE_BUCKET, TF_LOCK_TABLE, VPC_CIDR, ALB_ALLOWED_CIDR, DESIRED_COUNT, FARGATE_CPU/MEMORY, ENABLE_HTTPS, DOMAIN_NAME, HOSTED_ZONE_ID
↓ provisions infrastructure

Infrastructure as Code in TypeScript. Manages VPC, subnets, security groups, ALB, ECS cluster, IAM roles, CloudWatch logs. Remote state in S3 with DynamoDB locking.
